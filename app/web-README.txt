XArchive — standalone phone app (PWA)

1. Upload every file in this folder to one folder on an HTTPS website
   (e.g. a subdomain like https://xarchive.yourdomain.com/ on your own server).
   HTTPS is required for the app to install and work offline.
2. Open that address on your phone:
   - iPhone (Safari): Share → Add to Home Screen.
   - Android: browser menu → Install app / Add to Home screen.
3. Launch XArchive from the home-screen icon — it opens full screen, no browser bar.

Moving your list over: in the Claude version tap BACKUP → Copy data,
then in the phone app tap BACKUP → paste into Import → Import.
Data lives on the phone. Use BACKUP → Download file now and then as a safety copy.
